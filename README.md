# Alpha Seeker Market Data

Public, machine-readable snapshots derived from CME Group's free Daily Bulletin.

- `data/gc-options.json`: nearest standard COMEX Gold option (`OG`) expiry in the 5–45 DTE window.
- Updated after the preliminary and final bulletin windows on trading days.
- End-of-day reference data only; not a live trading feed.

No credentials, user data, Alpha Seeker source code, or trading orders are stored here.
